# Siddanth Raj - Personal Resume Website

A personal portfolio and resume website built with HTML5 and CSS3.

## Overview
This repository contains my personal resume website. It showcases my academic background, education at IIM Bangalore, core strengths, achievements, and contact details.

## Sections Included
- **About / Profile**: Introduction, educational focus, and background.
- **Education**: BBA in Digital Business & Entrepreneurship at IIM Bangalore and higher secondary schooling.
- **Strengths**: Analytical foundation, business curiosity, competitive mindset, and collaborative approach.
- **Skills & Focus**: Professional skills, career interests, and hobbies.
- **Achievements**: Sports honors (Badminton, Carrom) and academic qualifications (JEE Advanced).
- **Contact**: Direct contact information and links.

## Technologies Used
- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- **CSS3**: Flexbox, CSS Grid, custom properties (variables), and responsive media queries
- **Typography**: Space Grotesk & JetBrains Mono

## How to Run Locally
1. Clone or download the repository.
2. Open `index.html` in any modern web browser.

## Deployment
- **GitHub Pages**: Configured to deploy directly from the `main` branch.
- **Vercel**: Static deployment ready via `vercel.json`.
